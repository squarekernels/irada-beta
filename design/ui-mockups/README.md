Current brand review boards:

These replace the earlier blue boards for design review. The current app name is Irada.

The onboarding checkmark has been replaced with the Thought to Intent symbol. Primary accents are purple; light lavender supports dark-theme foregrounds. Raster generation can vary in exact color, lettering, icon fidelity and functional details. Use `../brand/irada/brand-manual.md` and its exact color tokens for implementation, and the SVG masters for logo geometry. In particular, semantic warning and destructive colors follow the guide rather than the purple treatment in the generated system-state board. Retain familiar completion controls, explicit action labels and a labeled Add tasks action in the implementation.
