# Irada brand mark

The selected **Thought to Intent** mark uses one continuous loop that resolves into an upright terminal. The loop represents unstructured input being held and reviewed; the rising terminal represents deliberate, user-approved progress.

## Final treatment

- Selected refinement: Balanced Loop
- Primary color: `#4B32F4`
- Primary dark text: `#11121A`
- Construction: one open Bézier path with a uniform rounded stroke
- Wordmark: editable live text with the font stack `Inter, SF Pro Display, Roboto, Arial, sans-serif`

## Files

- `irada-symbol.svg`: editable brand-color vector symbol
- `irada-symbol-mono.svg`: editable black vector symbol
- `irada-wordmark-horizontal.svg`: editable vector symbol plus live-text wordmark
- `irada-android-launcher.svg`: launcher composition preview; Android should implement the background and foreground as separate adaptive-icon layers
- `irada-refinement-board.png`: raster exploration showing the three refinements considered
- `irada-symbol-1024.png`, `irada-symbol-512.png`, `irada-symbol-256.png`: transparent brand-color PNG exports
- `irada-symbol-mono-1024.png`, `irada-symbol-mono-512.png`: transparent black PNG exports
- `irada-wordmark-horizontal-1024x400.png`: transparent horizontal wordmark export
- `irada-android-launcher-1024.png`: launcher preview export

The SVG files are genuine vector artwork. The wordmark remains live text so its wording, weight, and typeface can be edited; convert it to outlines in a vector editor only when a distribution workflow requires fully embedded letterforms.

The app name Irada and primary purple `#4B32F4` are locked. See `brand-manual.md` (editable guide), `Irada-brand-manual.pdf` (sharing copy), and `contrast-report.json` (computed color pairs). Supporting typography, palette and sizing proposals are identified in the manual.

Proposed clear space is 0.125 times the visible symbol height on every side, superseding the earlier half-stroke note. Do not add a dot, arrowhead, gradient, shadow, or internal decoration.
